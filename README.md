# 🔐 Cybersecurity Journey

¡Hola! Soy estudiante de Ingeniería de Sistemas (5to semestre) documentando mi proceso de aprendizaje en ciberseguridad. Este repositorio es mi bitácora pública: notas, writeups, scripts y recursos que voy usando en el camino.

## 🎯 Objetivo

Construir una base sólida en ciberseguridad, explorando distintas ramas (ofensiva, defensiva, seguridad web) para luego especializarme, mientras desarrollo un portafolio verificable de mi progreso.

## 🗺️ Cronograma de aprendizaje

| Semana | Enfoque | Recursos principales |
|--------|---------|----------------------|
| 1-2 | Fundamentos de Linux y redes | TryHackMe "Pre Security", NetworkChuck |
| 3-4 | Introducción a ciberseguridad | TryHackMe "Cyber Security 101", Kali Linux, OverTheWire Bandit |
| 5-6 | Herramientas y seguridad web | Nmap, PortSwigger Web Security Academy, videos de S4vitar |
| 7-8 | Práctica integrada | Máquinas easy de TryHackMe/HackTheBox, picoCTF |
